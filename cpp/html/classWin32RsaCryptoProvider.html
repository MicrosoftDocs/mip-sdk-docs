Verifies the signature of a message digest, using the specified hash algorithm. Decrypts the supplied signature using the public key, hashes the message digest, and compares the results.

Parameters
signatureThe signature to verify. This is the hash of the message encrypted with the private key.
messageDigestThe message digest to verify against the signature.
hashThe hashing algorithm used to verify the signature.
Returns
true if the signature is valid, false if it is not.
