Project Setup for Microsoft Visual Studio

Usage Instructions

Install package

Install the NuGet package [Microsoft.InformationProtection.{Policy/Protection}.Static.x.x.x] in your Visual Studio project.

Set Runtime Library:

Open your project in Visual Studio. Navigate to Project Properties -> Configuration Properties -> C/C++ -> Code Generation. Set the Runtime Library as follows: For Debug configuration: x86: Multi-threaded Debug (/MTd) x64: Multi-threaded Debug (/MTd) For Release configuration: x86: Multi-threaded (/MT) x64: Multi-threaded (/MT)

Include Directories:

Open your project in Visual Studio. Navigate to Project Properties -> Configuration Properties -> C/C++ -> General. Add the following directories to Additional Include Directories: ../../build/native/include/;%(AdditionalIncludeDirectories)

Preprocessor Definitions:

Open your project in Visual Studio. Navigate to Project Properties -> Configuration Properties -> C/C++ -> Preprocessor. Add the following preprocessor definitions: NO_MIP_IMPLEMENTATION;NO_CORE_IMPLEMENTATION;%(PreprocessorDefinitions)

Set Static Library Path (Linker Input):

Open your project in Visual Studio. Navigate to Project Properties -> Configuration Properties -> Linker -> Input. In the Additional Dependencies field, manually add the path to the static libraries as per your configuration: For x86 configuration: Debug: Add the path to Debug/x86 static libraries. Release: Add the path to Release/x86 static libraries. For x64 configuration: Debug: Add the path to Debug/amd64 static libraries. Release: Add the path to Release/amd64 static libraries.

Static libraries (x86 / x64):

Alternatively, you can directly specify the static library paths in the Linker options.

Additional Required Libraries:

If you are using this static library, you need to include the following Windows SDK libs in the Visual Studio Linker Additional Dependencies:

  • winhttp.lib
  • ncrypt.lib
  • Rpcrt4.lib
  • bcrypt.lib
  • wininet.Lib
  • Crypt32.Lib
  • Advapi32.lib
  • User32.lib
  • ws2_32.lib
  • Gdi32.lib
  • dnsapi.lib

Delay-Loaded DLLs:

Add mip_ClientTelemetry.dll to the Delay-Loaded DLLs in the Visual Studio Linker input section.

  • Open your project in Visual Studio.
  • Navigate to Project Properties -> Configuration Properties -> Linker -> Input.
  • Add mip_ClientTelemetry.dll to the Delay-Loaded DLLs field.
  • Add the following delay loaded dlls definitions: mip_ClientTelemetry.dll;%(DelayLoadDLLs)

Note on Auditing and Telemetry:

By default, MIP SDK specific auditing and telemetry logging is enabled and will use the dynamic mip_ClientTelemetry.dll, hence C runtime would be required. However, if you want to use your own audit and telemetry delegates, you can disable "is_audit_disabled" and "is_all_telemetry_disabled" custom settings passed in the DiagnosticConfiguration class, which eventually gets set in the MIP configuration object.

Note:

Make sure to adjust paths, configurations, and additional dependencies according to your project's setup. If you encounter any issues, refer to the documentation or contact the package maintainers.
