Detailed Description

The implementation class of interface class CPDF_CryptoHandler of Foxit core. CPDF_CryptoHandler is the abstract class for PDF cryptographic operations (encryption and decryption). This class works with security handler which provides algorithm and key info. Please refer to comments of CPDF_CryptoHandler.
