Detailed Description

The implementation class of interface class IFX_FileStream. It is invoked by pdf object model when reading and writing pdf document. IFX_FileStream is the file stream interface (reading & writing) of Foxit core. Please refer to comments of IFX_FileStream of Foxit core.
