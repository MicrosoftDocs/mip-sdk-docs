Detailed Description

It is used to wrap up the encrypted PDF file with the wrapper document. First, we have to set the payload info and the payload content. Then invoke CreateUnencryptedWrapper to output the final wrapped up PDF document. It is implemented by PDF object model, and it is invoked by PDF protector.
