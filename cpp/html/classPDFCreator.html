Detailed Description

It is used to create custom encrypted PDF file(be opposed to standard encryption like password encryption or certificate encryption) and decrypt it, according to "Microsoft IRM protection for PDF Spec-v2". It is implemented by PDF object model, and it is invoked by PDF protector.
