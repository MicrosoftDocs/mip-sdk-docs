Constructs a sealed-key writer, used for RSA envelope encryption. A random symmetric session key and - if necessary - initialization vector are generated. The session key is formatted with the instance of KeyFormatter, then encrypted using the public key this instance of RsaCryptoProvider was constructed with.

Parameters
keySizeThe size of the symmetric session key to generate.
keyAlgorithmThe algorithm to use for the symmetric session key.
paddingThe type of padding to use for the final RSA encryption.
paddingHashAlgorithmThe hash algorithm to use for the RSA padding.
ivA reference to an empty vector where the iv (if necessary) will be placed.
sessionKeyA reference to an empty vector where the FORMATTED AND ENCRYPTED session key will be placed.
keyFormatterAn instance of the KeyFormatter interface used to format the session key before encrypting it.
keyWriterA reference to an empty unique_ptr where the resulting SealedKeyWriter should be placed.

virtual bool RsaCryptoProvider::VerifySignature ( const std::vector< uint8_t > & signature,
const std::vector< uint8_t > & messageDigest,
CryptoHashAlgorithm hash ) const
pure virtual

Verifies the signature of a message digest, using the specified hash algorithm. Decrypts the supplied signature using the public key, hashes the message digest, and compares the results.

Parameters
signatureThe signature to verify. This is the hash of the message encrypted with the private key.
messageDigestThe message digest to verify against the signature.
hashThe hashing algorithm used to verify the signature.
Returns
true if the signature is valid, false if it is not.

Implemented in OpenSslRsaCryptoProvider, and Win32RsaCryptoProvider.
