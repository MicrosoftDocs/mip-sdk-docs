◆ GetCorrelationId()

string TelemetryContextImpl::GetCorrelationId ( ) const
overridevirtual

Get correlation ID, if any.

Returns
Correlation ID
Note
Individual class instances each hold their own TelemetryContext, however, not all contexts have a correlation ID. Usually, only important objects (e.g. profiles, engines, handlers) use correlation IDs to facilitate debugging via telemetry to track the creation/usage of those objects
