# MIP SDK for C Reference

The Microsoft Information Protection (MIP) SDK for C allows developers to manage and apply data protection policies to data and other digital assets. For guidance on how to use it, see [Microsoft Information Protection SDK documentation](https://learn.microsoft.com/information-protection/develop/).

The MIP SDK for C reference includes the following [data structures](annotated.html):

| Data Structure Name | Description |
|---------------------|-------------|
| [mip_cc_application_action_state](structmip__cc__application__action__state.html) | Represents the current state of the application as it performs a label-related operation |
| [mip_cc_application_info](structmip__cc__application__info.html) | A struct that includes application-specific information |
| [mip_cc_async_task](structmip__cc__async__task.html) | Defines a single async task dispatch request |
| [mip_cc_document_state](structmip__cc__document__state.html) | Represents the current state of a label-aware document |
| [mip_cc_error](structmip__cc__error.html) | Error information |
| [mip_cc_feature_override](structmip__cc__feature__override.html) | Defines a single feature's enabled/disabled state |
| [mip_cc_guid](structmip__cc__guid.html) | GUID |
| [mip_cc_http_header](structmip__cc__http__header.html) | HTTP request/response header |
| [mip_cc_http_request](structmip__cc__http__request.html) | HTTP request |
| [mip_cc_http_response](structmip__cc__http__response.html) | HTTP response |
| [mip_cc_identity](structmip__cc__identity.html) | A struct that includes application-specific information |
| [mip_cc_kv_pair](structmip__cc__kv__pair.html) | Key/value pair |
| [mip_cc_oauth2_challenge](structmip__cc__oauth2__challenge.html) | Information provided by a server to generate an OAuth2 token |
| [mip_cc_user_rights](structmip__cc__user__rights.html) | A group of users and the rights associated with them |
| [mip_cc_user_roles](structmip__cc__user__roles.html) | A group of users and the roles associated with them |
