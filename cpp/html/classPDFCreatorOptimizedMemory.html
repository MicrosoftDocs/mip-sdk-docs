Detailed Description

An optimized memory creator to encrypt/decrypt a PDF file(be opposed to standard encryption like password encryption or certificate encryption) according to "Microsoft IRM protection for PDF Spec-v2".

Note
Compared with PDFCreator, this class does not use temporary files and large memory in the process of processing file encryption and decryption. You can update the properties of the output file synchronously during the process.
